# 🛒 E-Commerce Backend

## A Real-World Scalable Backend Application

This project simulates a real-world backend environment, focusing on scalability, security, performance, and clean API design. It provides a robust backend system for managing an e-commerce product catalog, complete with authentication, filtering, sorting, pagination, and documentation.

### 🚀 Overview

The backend is designed to handle core e-commerce operations, including product management, category organization, user authentication, and optimized API endpoints. It reflects real-world backend engineering challenges and best practices.

## 🎯 Project Goals
### 1. CRUD APIs

Full CRUD functionality for products and categories

Secure user authentication via JWT

Admin-level and user-level permissions (optional)

### 2. Filtering, Sorting & Pagination

Filter by category

Sort by price or name

Efficient pagination for large datasets

### 3. Database Optimization
Optimized relational schema
Use of indexes for high-performance queries

Avoiding N+1 queries with select_related / prefetch_related
